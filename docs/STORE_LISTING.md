## Full description
TagVerity is a privacy-first NFC inspector for checking tags in the real world.
Scan an NFC tag to understand what your phone can read, review standard NDEF content when available, see public tag technology information, and get a simple PASS, LIMITED, or REVIEW result.
TagVerity supports the NFC families exposed by modern phones, including NFC-A / NFC-B, NFC-V / ISO 15693, and NFC-F / ISO 18092. On iPhone, NFC-F support is intentionally limited to the standard NFC Forum Type 3 / NDEF system code.
When you need to check more than one tag, Batch Scan keeps a running list, highlights repeated comparable identifiers, counts tags that need review, and lets you share a CSV report. A repeated identifier is a useful QA signal, not proof that two physical tags are the same.
Key features:
- Read-only NFC inspection
- Clear PASS / LIMITED / REVIEW summaries
- Standard NDEF inspection
- NFC-A/B, NFC-V, and NFC-F coverage where the phone exposes them
- Manual and continuous batch scanning
- Possible repeated-ID detection when identifiers are comparable
- Searchable local scan history
- JSON and CSV reports
- Privacy controls for UID, NDEF, and linkable technical fields
- No account, ads, analytics, or automatic cloud upload
TagVerity does not clone cards, emulate tags, recover security keys, bypass access controls, or modify protected tag memory.
