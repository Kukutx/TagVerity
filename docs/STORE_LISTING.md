## Full description

TagVerity is a privacy-first NFC inspector for checking tags in the real world.

Scan an NFC tag to understand what your phone can read, review standard NDEF content, see public tag technology information, and get a simple PASS, LIMITED, or REVIEW result.

When you need to check more than one tag, Batch Scan keeps a running list, highlights repeated tag fingerprints, counts tags that need review, and lets you share a CSV report.

Key features:
- Read-only NFC inspection
- Clear tag health assessment
- Standard NDEF inspection
- Batch scanning and duplicate detection
- Searchable local scan history
- JSON and CSV reports
- Privacy controls for UID, NDEF, and linkable technical fields
- No account, ads, analytics, or automatic cloud upload

TagVerity does not clone cards, emulate tags, recover security keys, bypass access controls, or modify protected tag memory.
